# TaskTrack

TaskTrack is a command-line task manager created for CPS 310.

## Current Features

* Add new tasks to the task list
* View all saved tasks in a numbered list

## Running the Program

```powershell
python tasktrack.py
```

This command runs the `tasktrack.py` file and starts the task tracking program in the terminal.

## Current Limitation

Tasks are currently stored only while the program is running. When the program is closed, the tasks are deleted and will not be available the next time the program starts.
